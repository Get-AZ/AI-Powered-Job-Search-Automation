# Security and Privacy Checklist

- [x] Public template excludes original candidate-profile prompts.
- [x] Public template excludes credential references and spreadsheet IDs.
- [x] Public template excludes pinned execution data.
- [ ] Review each file and commit before sharing publicly.
- [ ] Keep n8n API credentials and Google OAuth tokens in n8n credential storage.
- [ ] Keep personal CVs, application drafts, and private Google Sheets out of public repositories.
- [ ] Confirm job-board API terms, quotas, and acceptable use.
- [ ] Validate AI-generated letters before sending; do not assume work authorization.
- [ ] Configure least-privilege Google Sheets access and monitor automation failures.

Never upload the original private n8n export without a separate security review.
